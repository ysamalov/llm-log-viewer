# Журнал запросов к LLM

SPA-приложение для просмотра и анализа журнала запросов к языковым моделям. Построено на React + TypeScript (Vite), стилизовано Tailwind CSS с поддержкой тёмной темы.

## Возможности

- **Таблица запросов** — пагинация (20 записей на страницу), сортировка по времени, задержке и стоимости
- **Фильтры** — по модели, статусу (200/429/500) и диапазону дат; состояние фильтров сохраняется в URL
- **Карточки итогов** — число запросов, доля ошибок, средняя задержка, общая сумма
- **График задержки** — средняя задержка по дням в разрезе моделей (Recharts)
- **Тёмная тема** — переключатель в шапке, настройка сохраняется в localStorage
- **Адаптивность** — работает от 360 px
- **Пустые и ошибочные состояния** — отображаются при отсутствии данных или ошибке загрузки

## Стек

- React 18 + TypeScript
- Vite
- TanStack Query (загрузка данных с имитацией сетевой задержки 500 мс)
- Recharts (график)
- React Router (фильтры в URL)
- Tailwind CSS (стили + тёмная тема)
- Vitest (тесты)

## Быстрый старт

```bash
# Установка зависимостей
npm install

# Генерация тестовых данных (550 записей за последние 30 дней)
npm run generate-data

# Запуск dev-сервера
npm run dev
```

Приложение откроется на http://localhost:5173

## Тесты

```bash
# Запуск тестов
npm test

# Запуск в watch-режиме
npm run test:watch
```

Тесты покрывают:
- `filterLogs` — фильтрация по модели, статусу, диапазону дат, комбинации фильтров, пустые данные
- `sortLogs` — сортировка по всем полям в обоих направлениях, иммутабельность
- `paginateLogs` — корректная нарезка страниц, граничные случаи
- `getUniqueModels` — уникальные модели, сортировка
- `calculateSummary` — подсчёт итогов, доля ошибок, средняя задержка, пустой массив

## Сборка

```bash
npm run build
```

Результат в папке `dist/`.

## Структура данных

Каждая запись в `data.json`:

```json
{
  "id": "req_00001",
  "timestamp": "2024-06-15T12:00:00.000Z",
  "model": "gpt-4",
  "status": 200,
  "input_tokens": 1500,
  "output_tokens": 800,
  "latency_ms": 2300,
  "cost_usd": 0.093
}
```

Модели: `gpt-4`, `gpt-3.5-turbo`, `claude-3-opus`, `claude-3-sonnet`
Статусы: `200` (успех), `429` (rate limit), `500` (ошибка сервера)
